Hello world

This page is served by nginx from inside the hello-nginx snap.

Serve your own site the same way

hello-nginx is also a template. Customize this snap from its source by replacing this page with your website. You then build a snap of your own that contains your site and the nginx server that serves it.

Source and documentation: github.com/carlosbravoa/hello-nginx

Or serve a git repository

No build needed: point this snap at a public repository with your static files. It fetches the latest commit and serves it, and can follow the branch as you push.

sudo hello-nginx deploy https://github.com/me/my-site.git
sudo hello-nginx auto-update 15m
sudo hello-nginx rollback        # back to the previous commit

Why snap a whole site

The content is versioned with the server:

  • Updates are all-or-nothing. snap refresh swaps the site and nginx together, so nobody sees a half-copied site.
  • Rollback is one command. snap revert my-site brings back the previous site.
  • Channels become environments. For example, edge can be staging and stable production, with snapcraft release as the promotion step.
  • cloud-init becomes trivial. It's just snap install my-site, with no setup steps after it.

Make it yours

This page is site/index.html in the source. Replace the contents of site/ with your website, then:

scripts/rename.sh my-site
snapcraft pack
tests/lxd-smoke.sh
snapcraft upload my-site_*.snap --release=edge

On the server

sudo hello-nginx port 80
hello-nginx status
sudo hello-nginx logs -f
sudo snap revert hello-nginx    # back to the previous site

Developer pages

Off by default. Turn them on with sudo hello-nginx dev-pages on for a dashboard at /_hello/, a request echo at /_hello/request and nginx counters at /_hello/status.
